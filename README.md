# 亀卜シミュレーター (kiboku)

古代中国の占術「亀卜」をブラウザで再現するシミュレーターです。Canvas 上の亀甲に加熱の跡(灼)を描き、ひび割れ(卜)の結果を占います。

## 使い方

`index.html` をブラウザで開くだけで動作します(ビルド不要)。

## 公開URL

https://hokonoko.github.io/kiboku/

## 構成

- `index.html` — エントリポイント
- `src/` — アプリ本体(コアロジック、描画、音声、演出など)
- `tools/` — 開発用チェックツール
- `docs/` — 設計・実装計画ドキュメント
