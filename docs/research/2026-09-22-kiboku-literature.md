## 1. 施術の手順

### 1.1 殷（中国）の亀卜

| 手順 | 文献・出典 | 内容 |
| --- | --- | --- |
| 整治・甲橋切断 | 漢字文化資料館「漢字の来た道」PartⅠ（高久由美） | 亀骨格は背甲・腹甲が甲橋で繋がり、**甲橋を刃物で切断**して背甲・腹甲に分ける。占い記録には主に**腹甲**を使用、背甲は稀。 |
| 鑽・鑿 | 同上 | 腹甲・背甲の**内側（裏面）**に、表面に亀裂を誘導するために **鑽（さん）＝円形の浅い凹み** と **鑿（さく）＝アーモンド形の深い凹み** の2種を穿つ。 |
| 灼 | 『史記』巻128「龜策列伝」 | 「古之灼龜，取生荊枝及生堅木燒之，斬斷以灼龜」＝生えた**荊（にれ）の枝や堅木を焼き、切って**龜を灼く。また「灼亀観兆」。 |
| 方位・尺寸 | 『史記』龜策列伝 | 「其卜必北向，龜甲必尺二寸」＝占うときは必ず北を向き、龜甲は必ず一尺二寸とする。 |
| 兆の出現 | 同上（台大科教中心「商代晚期の『占』『卜』と吉凶判断」） | **施灼点の反面（表面）に、縦・横2方向の裂が現れる。縦を「兆幹」、横を「兆枝」** と呼ぶ。漢字「卜」はこれの象形。 |
| 兆の読解 | 同上 | 兆幹と兆枝の**夾角が70・80・90・100度以上**の卜兆は、吉兆と判断された確率が有意に高い（約2,000例の統計）。ただし統一法則はなく、因人因事で異なったとの指摘もある。 |
| 刻辞 | 光明日报「甲骨刻辞记录的意义」ほか | 一条の卜辞は **叙辞（前辞：日付＋貞人）／命辞（問い）／占辞（王の判断）／驗辞（後の応験）** の4部から成る。例：「王占曰︰吉。」 |
| 記日 | 台大科教中心（註一） | 殷は**干支で日を記**し、十日を一旬とする。癸日（旬末）に次の旬を卜する傾きが強く、癸日の卜は他日比で約4倍。 |

- 亀卜の対象：征伐・狩猤・畜牧・農事・災害・疾病など（教育百科「甲骨檔案」）。
- 五体の担当：『周礼』春官では 菙氏が灼龜、卜師が兆体を辨え（占龜）、大卜が兆象を解して吉凶を命じる（命龜）。

### 1.2 周礼・洪範による「兆」の分類（実在する分類）

- 『周礼』春官・**大卜**：「掌三兆之法，一曰**玉兆**，二曰**瓦兆**，三曰**原兆**。其經兆之體，皆百有二十，其頌皆千有二百。」
- 『周礼』春官・**卜師**：「掌開龜之**四兆**：一曰**方兆**，二曰**功兆**，三曰**義兆**，四曰**弓兆**。凡卜事，視高。**揚火以作龜，致其墨**。凡卜，辨龜之上下、左右、陰陽。」
- 『礼記』玉藻：「**卜人定龜，史定墨，君定体**」（卜人は龜を選び、史が墨で兆を定め、君が体を定める）。
- 『書経（尚書）』**洪範** 七稽疑：「曰**雨**，曰**霽**，曰**蒙**，曰**驛**，曰**克**，曰貞，曰悔，凡七。**卜五**，占用二。」「三人占，則從二人之言。」
  - 異本では「圇」（一作 驛）「雺」（一作 蒙）とも表記される。
  - 伝統的な訓釈：雨＝雨の如く／霽＝開く（『卜法詳考』所収の註に「霽者開」「雨者如雨」）／蒙＝晦れる／驛＝絶え絶え・断続／克＝相剋・交錯。

→ 本サイトでは、**洪範の五兆（雨・霽・蒙・驛・克）**を実在する「兆」の分類として採用した。
   日本の亀卜で用いられた兆の名称を伝える史料は現存しないため、漢籍側の実在分類を用いるのが誠実である。

## 2. 日本の亀卜

### 2.1 材料と所作

- 腹甲を乾燥させ薄く加工して用いる。日本列島では**ウミガメの甲羅に溝や穴**を開け、
  火で熱した **波波迦木（ははかぎ＝上溝桜）** あるいは **箒（サクラなどの木片）** を押し付ける。
  **甲羅を直接炎で加熱することはない**（日本語Wikipedia「亀卜」／鎌田純一『平成大禮要話』）。
- 古墳時代後期（6世紀）の卜甲が現状最古（間口洞穴遺跡）。
  それ以前は鹿・イノシシの肩甲骨による**太占（骨卜）**のほうが古い。
- 遺構にみる溝・穴＝中国の鑽・鑿に対応する（卜部氏研究等）。

### 2.2 律令国家の制度

- 『養老令』神祇令により**卜部**を神祇官に置く。対馬・壱岐・伊豆の三国から選抜。
- 『延喜神祇式』臨時祭「宮主ト部」：「其ノ卜部ハ三国ノ卜術ノ優レ長ズル者ヲ取ル〈**伊豆五人・壱岐五人・対馬十人**〉」。
- 『新撰亀相記』：**天長7年（830）卜部遠継撰**と伝わる卜占書。全4巻（甲・乙・丙・丁）のうち甲巻が現存。
  書名の「亀相」は**亀卜のひびの形状から時勢を見通す**意。丁巻は目録に「**神人兆三卦称候**」。
- 『日本三代実録』貞観14年（872）4月24日癸亥条：壱岐出身の**伊伎是雄**の卒伝に
  「神代より始め、**亀卜に仕奉してきた**」と見える。
- 宮中では**大嘗祭の斎田点定の儀**（悠紀・主基の国を選ぶ）に亀卜を用いる（2019年令和元年にも施行）。

### 2.3 対馬・豆酘 雷神社「亀卜神事（サンゾーロー祭）」（国選択無形民俗文化財）

- 毎年**旧暦1月3日**、アカウミガメの**六角形の甲羅片**に、**火鉢であぶった桜の木**を押し当て、
  生じたひび割れ・色で1年の吉凶を占う。
- 卜者は「**トホカミエミタメ**」と3度唱えた後、施行する。結果は**筆で半紙に書き留め**、読み上げる。
- 住民の唱和「おー、**サンゾーロー**（参候）」。
- 卜者は**豆酘の岩佐家が世襲**（2019年時点で69代目、甥が70代目に継承）。伝承書『**亀卜伝義抄**』。
- 作法の記録：元禄九年 藤斎延撰『**対馬国亀卜次第**』、伴信友『**正卜考**』。
- 『対州神社誌』（貞享3年・1687）：旧暦十月末の卯日〜十一月初の酉日の間に「焼占」を行い、
  **卜事の前後7日間は往来を禁じる**（厳粛な環境の確保）。
- 実際の判定語（報道より）：豆酘地区「**吉**」「**安**」「**上々**」、
  農業「平年作」「吉」、水産業「**良**」「不漁」、天候「**並**」「不動」、
  経済「上々」「重」、天災「有」「吉」、震災「軽震」。

→ 本サイトの5段階判定は、**殷卜辞の「大吉・吉・不吉」と対馬亀卜神事の「安・並」**を組み合わせた。
