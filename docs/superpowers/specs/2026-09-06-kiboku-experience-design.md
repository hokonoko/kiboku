# 亀卜シミュレーター体験拡充 設計書

- 日付: 2026-09-06
- ステータス: ドラフト（ユーザーレビュー待ち）
- 前提: `2026-07-25-kiboku-simulator-design.md` で構築された現行版を拡張する

## 目的

現行の亀卜シミュレーター（単一 `index.html`、Canvas 2D、外部依存ゼロ）に対し、
**占い結果の充実**・**演出強化**・**描画品質改善**を行い、体験の深みとリプレイ性を高める。

## 確定要件（ヒアリング結果）

| 項目 | 決定 |
|---|---|
| 改善方向 | 体験・機能の拡充 ＋ パフォーマンス・描画品質 |
| 体験の重点 | 占い結果の充実、演出の強化 |
| 単一ファイル制約 | 緩和可（複数ファイル構成を許容） |
| JS分割方式 | 通常 `<script src>` ＋ `window.Kiboku` 名前空間（`file://` 直開きを維持） |
| PNG保存ボタン | 実装する |

## スコープ

### 実施するもの

- JS ファイル分割（通常 `<script src>` ＋ `window.Kiboku` 名前空間）
- 占い結果の充実：卜兆の「型」判定、カテゴリ別解釈、根拠ひびのハイライト
- 演出強化：Web Audio プロシージャル音響、煙・火花パーティクル
- 描画品質：完成ひびのオフスクリーン焼き付け、ひびの2重ストローク質感
- 結果の PNG 保存ボタン

### 実施しないもの（YAGNI）

- URL共有・占い履歴の保存
- モバイル最適化（タッチ・レスポンシブの専用対応）
- 熱揺らぎディストーション（煙・火花で代替）
- 史実文献に基づく厳密な卜兆解釈（オリジナルの型分類とする）

## ファイル構成

```
index.html      … マークアップ・CSS・scriptタグ列挙
src/
  core.js       … 名前空間初期化、mulberry32/makeNoise1D/lerp/clamp/dist
  sim.js        … simulateCracks, computeMetrics（純粋ロジック）
  fortune.js    … judgeFortune, classifyPattern, interpretFortune（純粋ロジック）
  plastron.js   … 腹甲パス・ベースレイヤー描画
  effects.js    … 加熱グロー、煙・火花パーティクル
  audio.js      … Web Audio 音響
  app.js        … 状態機械・イベント配線・メインループ
tools/headless-check.js … core/sim/fortune を順に vm 評価して検証（拡張）
```

- script 読込順: `core → sim → fortune → plastron → effects → audio → app`
- 各ファイルは `window.Kiboku = window.Kiboku || {}` に関数を追加し、UI層は `Kiboku.xxx` 経由で参照
- 純粋ロジック（core/sim/fortune）はDOM非依存を維持し、既存ハーネスの方式を踏襲

## 占い結果の充実

### 型判定 `classifyPattern(metrics)`

直線性・枝の向き分布（上/下）・左右バランス・枝密度から、6〜8種の型に分類する
（例：「直達型」「昇枝型」「垂蔭型」「分岐型」「細流型」）。各型に1〜2文の説明を持つ。

判定に必要なため `computeMetrics` に以下を追加する：

- 左右枝数比（`sideBalance`）
- 上向き枝率（`upwardRatio`）

### カテゴリ別解釈 `interpretFortune(metrics)`

既存の `judgeFortune` は「総合」として維持し、仕事・恋愛・健康の3カテゴリを追加。
カテゴリごとにメトリクスの重み付けを変えてスコアリングする：

- 仕事: 主線の安定（straightness）重視
- 恋愛: 枝の上向き（avgTiltDeg）と左右バランス（sideBalance）重視
- 健康: 主線の長さ（mainLen）重視

結果パネルに「総合/仕事/恋愛/健康」タブを追加し、切替でランク・解釈文を表示する。

### 根拠ハイライト

`interpretFortune` の戻り値に、判定の根拠となったポリラインのインデックス配列（`evidenceIndices`）を含める。
結果表示時にそのひびだけ金色でフェード強調する。

## 演出強化

### 音響（全て Web Audio でプロシージャル生成、音声ファイル不使用）

- 灼き中: 低音の唸り＋炭のパチパチ（フィルタ済みノイズバーストをランダム間隔で）
- ひび成長: 前線の伸びに連動した「ピシッ」（短い高域バースト。主線は低め、枝は高め）
- 結果表示: ランクに応じた和風の余韻（大吉=明るい2音、凶=低い単音の減衰）
- AudioContext は初回クリック時に生成・resume（自動再生ポリシー対応）
- パネルにミュートボタンを追加。非対応環境では無音で継続

### パーティクル

- 煙: 灼き点から上昇する煙（最大30個、拡大しながら減衰）
- 火花: HEATING中に飛び散る火花（重力付き）
- RESULT移行後は新規発生を止め、自然消滅させる

## 描画品質・パフォーマンス

- **完成ひびの焼き付け**: ひび専用オフスクリーン（crackLayer）を用意し、開示完了したポリラインは
  一度だけ焼き付ける。以後のフレームは `baseLayer + crackLayer + 成長中ポリライン` の描画で済み、
  CRACKING後半〜RESULTのコストを削減する
- **ひびの質感向上**: 焼き付け時に「暗い芯＋やや明るい縁」の2重ストロークで、
  甲羅に食い込んだ質感を出す（コストは焼き付け時のみ）

## PNG保存

- 結果パネルに「画像を保存」ボタンを追加
- 現在のキャンバス内容（腹甲＋ひび＋演出を含む最終フレーム）を `canvas.toDataURL('image/png')` で
  PNG化し、ダウンロードリンクとして保存する
- ファイル名は `kiboku-<seed>.png` とする

## テスト方針

- `tools/headless-check.js` を拡張: `core/sim/fortune` の3ファイルを順に評価し、
  既存テストに加えて以下を検証する
  - `classifyPattern`: 各型への分類が機能し、全ケースでいずれかの型が返る
  - `interpretFortune`: 各カテゴリのランクと解釈文が返る
  - 拡張メトリクス（sideBalance, upwardRatio）の範囲
- 音響・パーティクル・ハイライト・PNG保存は手動確認チェックリストで検証する
