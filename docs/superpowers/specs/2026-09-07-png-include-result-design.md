# PNG保存への占い結果同梱 設計書

- 日付: 2026-09-07
- ステータス: ドラフト（ユーザーレビュー待ち）
- 前提: `2026-09-06-kiboku-experience-design.md` で実装済みのPNG保存機能を拡張する

## 目的

現在の「画像を保存」はキャンバス（腹甲＋ひび）のみを保存し、結果パネル（HTMLオーバーレイ）
は画像に写らない。占い結果（ランク・型・解釈）を画像内に一緒に保存できるようにする。

## 確定要件

| 項目 | 決定 |
|---|---|
| 含める結果 | 選択中のタブ（総合/仕事/恋愛/健康）の内容 |
| レイアウト | 腹甲画像の下にフッター帯を追加 |
| 対象外 | 画面Canvas自体の変更なし |

## 方式

保存時に専用エクスポートCanvasを組み立てる:

- サイズ: cv ビットマップ（LW×DPR × LH×DPR）＋ フッター帯（論理220px × DPR）を縦に連結
- 上段: 現在の cv の内容をそのまま drawImage
- フッター: 背景 `#17140f`、上端に境界線
  - 左側: ランク文字（`RANK_COLORS` で色分け、大きめのフォント）
  - 右側: 型名＋説明、解釈理由（複数行）、シード／スコア行
- データソース: `interpCache[currentCategory]` と保持済みの型情報
- ダウンロード方式・ファイル名は現状維持（`kiboku-<seed>.png`）
- 結果未表示（`interpCache` が空 / lastSnap なし）の場合は従来どおり腹甲のみ保存

## 変更箇所

- `src/app.js`: savepng ハンドラの再実装のみ（`index.html` 変更なし）
- `showResult` で型情報（name/description）を保持する変数を追加

## テスト方針

- `node --check src/app.js` で構文確認
- `node tools/headless-check.js` でロジック無影響を確認（24/0）
- ブラウザで手動確認: 結果表示中に保存→ランク・型・理由・シードが画像内に含まれること、
  タブ切替後に保存→選択中カテゴリの内容が保存されること、結果未表示で保存→フッターなし
