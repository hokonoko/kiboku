# 亀卜シミュレーター 設計書

- 日付: 2026-07-25
- ステータス: 承認済み（ユーザーによるデザインレビュー済み）

## 目的

古代日本の亀卜（亀の腹甲を灼いて卜兆＝ひび割れで吉凶を占う）を題材にした、
**ひび割れ生成アルゴリズムとアニメーション表現が主眼の技術デモ**。

## 確定要件（ヒアリング結果）

| 項目 | 決定 |
|---|---|
| 目的 | 技術デモ |
| 操作 | フルインタラクティブ（灼く位置をクリック指定、強さ・時間を調整、毎回プロシージャル生成） |
| ひびのスタイル | 伝統的な「卜」型（主縦線＋横枝） |
| 吉凶の解釈 | 簡易解釈あり（大吉〜凶＋短い解説） |
| 技術構成 | 単一HTML、バニラJS、Canvas 2D、外部依存ゼロ |
| ビジュアル | リアル寄りの腹甲（骨質感・暖色系・甲板の継ぎ目） |
| 生成方式 | C: 誘導付き成長型 |

## アーキテクチャ

- `index.html` 1ファイルのみ。CSS/JS全内蔵。ダブルクリックで開いて動作する。
- JSは機能ごとにセクション分割し、純粋関数（乱数・ジオメトリ生成・スコアリング）を
  レンダリングから分離する。コンソールから単体確認可能な構造にする。

```
[乱数/ノイズ] → [ひび成長シミュレータ] → [吉凶判定]
                      ↓                      ↓
[腹甲描画] ← [描画層] ← [UI/状態管理] ← [メインループ]
```

## 画面・操作フロー

- 中央にCanvas（腹甲）、下部に操作パネル：
  **強さスライダー**・**時間スライダー**・「占い直す」ボタン
- 状態遷移（状態機械）：

```
待機(IDLE) --腹甲クリック--> 灼き中(HEATING)
  --(時間パラメータ分経過)--> ひび成長(CRACKING)
  --(全前線停止)--> 結果表示(RESULT) --占い直す--> IDLE
```

- IDLE中のみスライダー変更・クリックを受け付ける。
- 結果表示では「同じ条件でもう一度」（同シード再実行）も可能。

## ひび生成アルゴリズム（方式C: 誘導付き成長型）

- **シード付き乱数**（mulberry32）。シードを結果画面に表示し再現可能にする。
- **主縦線**：クリック点から上下2方向に成長する「前線」を持つ。
  毎フレーム、垂直基調＋ノイズ由来の揺らぎで進行方向を更新。
- **横枝**：主線上の一定間隔（＋ジッタ）で左右に分岐する前線を発生。
- 各前線は `位置・方向・速度・残エネルギー・ノイズ位相` を持ち、
  エネルギー枯渇または甲羅外周（`isPointInPath`判定）で停止。
- 成長中の全ジオメトリをポリライン＋メタデータ（主線/枝、分岐元、角度）として記録し、
  描画と吉凶判定の両方に使用する。

### パラメータ連動

| 入力 | 連動先 |
|---|---|
| 強さ (0-100) | 枝の本数(1〜5対)・枝の長さ・枝の角度の勢い・総エネルギー |
| 時間 (0-100) | 灼きアニメ時間(1〜4秒)・主線の長さ・主線の真っ直ぐさ（長いほど明確な卜型） |

## 吉凶判定

記録した実測ジオメトリからスコアリング：

- **枝の平均角度**：上向き=吉／下向き=凶寄り
- **枝の本数と長さ**：多く長い=力強い=吉
- **主線の真っ直ぐさ**：真っ直ぐ=安定=吉

スコアを `大吉/吉/中吉/小吉/凶` にマッピングし、実測値を根拠にした
短い解説を表示（例：「枝が力強く上を向いています」）。

## ビジュアル

- 腹甲は手続き描画：ベジェで左右対称の輪郭、暖色系骨質グラデーション＋ノイズ質感、
  甲板の継ぎ目（喉甲〜肛甲の6対相当）を曲線で表現。
- ひびは暗色のギザついたポリライン。成長中は先端がわずかに発光し、定着後は沈静。
- 灼き中は押し当て点に放射状の赤熱グロー＋卜窩（焦げた窪み）を表現。

## テスト方針

- 自動テストフレームワークは導入しない。
- 手動検証：各状態遷移、スライダー両端値、甲羅端ギリギリのクリック、シード再現性。
- 実装後の検証として、Node.jsでスクリプト部の構文チェックと、
  DOM/Canvasをスタブしたヘッドレスハーネスで純粋ロジック（乱数・成長・判定）を
  実際に駆動して確認する。
